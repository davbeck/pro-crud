# ProPresenter And pro-crud Documentation

This documentation explains how to use `pro-crud` and work with ProPresenter
files. It describes supported behavior and identifies version-specific behavior
and compatibility limits.

- [CLI usage](../README.md): installation, inspection, editing, creation, and
  rendering commands.
- [Format reference](Format/README.md): containers, presentations, playlists,
  themes, text builds, and rendering semantics.
- [Working with ProPresenter](ProPresenter.md): importing prepared documents.

The format reference is bundled with the CLI. `pro-crud docs format` prints the
core format pages; `pro-crud docs protobuf` describes the bundled schema.
