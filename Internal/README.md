# Internal Contributor Documentation

This directory holds research evidence, experiment plans, implementation
proposals, progress notes, and fixture provenance. It is contributor context
and is not bundled with the CLI's public documentation.

Published usage and compatibility guidance belongs in [Docs](../Docs/README.md).
State supported behavior there directly, qualify version and scope, and
identify tool policies separately from native ProPresenter behavior. Keep
unresolved hypotheses, experiment procedures, and progress history here.

## Format Research

[Fixture export workflow](../Fixtures/ProPresenter/README.md) describes native
reference generation and snapshot installation.

- [Experiment backlog](Research/Format/Experiments.md): research procedures,
  completed comparisons, and remaining questions.
- [Theme research](Research/Format/ThemeDocuments.md): controlled input layouts,
  before/after results, Look captures, and unresolved resolver behavior.
- [Build and Delivery research](Research/Format/TextBuilds.md): native samples,
  indexing hypotheses, proposed commands, and the experiment matrix.
- [Planning Center research](Research/Format/PlanningCenterPlaylists.md): local
  workspace inspection, visibility diffs, and service-workflow experiments.
- [Rendering research](Research/Format/RenderingBehavior.md): fixture evidence,
  renderer validation strategy, and gaps in native comparisons.
- [Presentation evidence](Research/Format/PresentationEvidence.md): element
  paint order and background fixture notes.

The research records migrated on September 5, 2026 preserve their original
context, including historical descriptions of tool support. They are not a
second maintained usage reference. Check current source and public docs before
using a recorded implementation status to plan new work.
