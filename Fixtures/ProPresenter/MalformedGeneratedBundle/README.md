# Malformed Generated Bundle

`MalformedGeneratedBundle.probundle` is a deterministic, media-free reduction
of the stale text-metadata failure first found in a real bundle generated by
this tool. Its five 854×480 slides isolate:

1. an out-of-bounds `originalFontSize` range
2. single- and two-face RTF font tables with standalone `fontScaleFactor`
3. valid, negative-start, reversed, and past-end custom-attribute ranges
4. explicit line breaks with stale `originalFontSize`
5. element opacity at zero, 25%, and 100%

All text uses built-in Helvetica with deliberately contradictory Times
compatibility metadata on malformed elements, so the bundle does not depend
on installed fixture fonts. The full-canvas background is the last stored
element because ProPresenter paints the repeated element field in reverse.

Generate or verify the archive:

```sh
swift run FixtureGenerator generate-malformed-bundle
swift run FixtureGenerator generate-malformed-bundle --check
```

Import the generated archive into ProPresenter, then use **File → Export →
Slide Images**, select **PNG (without slide background color)**, and save all
five numbered PNGs in one directory. Install them with:

```sh
swift run FixtureGenerator install-malformed-bundle-references \
  --from /path/to/exported-pngs \
  --replace
```

The checked-in references were exported from the generated archive by
ProPresenter 21.4 (build 352583705) on macOS 26.5.2. They demonstrate that an
oversized `originalFontSize` range still changes overlapping glyphs,
`fontScaleFactor` alone does not change the tested output, malformed range
shapes do not remove inline bold, zero opacity hides shape appearance, and
text glyphs remain fully visible regardless of the text element's opacity.
