# List Indentation

`ListIndentation.probundle` is a media-free ProPresenter fixture with three
native list configurations:

- disc markers styled separately from their list item text;
- decimal markers with distinct tab-stop positions; and
- nested lower-alpha/lower-roman lists with independent first and second tab
  stops at each depth.

The accompanying reference PNGs are checked in under
`Tests/ProCRUDCoreTests/__Snapshots__/ListIndentationFixtureTests/`. They were
exported from ProPresenter 21.4 on macOS 26.5.2 using **File → Export → Slide
Images**, **PNG (without slide background color)**, with **Include Media
Actions** enabled. The user supplied the source bundle and exports on 2026-08-20.
